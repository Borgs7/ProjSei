About

What is SeiScanPH?

SeiScanPH is an earthquake hazard mapping tool that estimates how strongly the ground shakes at any location during a modeled seismic scenario. It turns raw peak ground acceleration (PGA) data into an intuitive, color-coded intensity map based on the Modified Mercalli Intensity (MMI) scale. The goal is to make seismic hazard information accessible and easy to interpret for planners, researchers, and the public.

How it works

From database to map

SeiScanPH is built in three simple layers. Hazard data lives in a spatial database, an API serves it on request, and the map turns it into an interactive visualization you can click and explore.

The science behind the intensity

Ground shaking is measured as peak ground acceleration (PGA), but PGA on its own is hard to interpret. SeiScanPH converts PGA into the Modified Mercalli Intensity (MMI) scale — the familiar “weak” to “extreme” ratings — using the relationship from Wald et al. (1999), which maps instrumental ground motion to felt intensity.
